# Compass Transfer

## Запуск и управление сервисами

Этот проект использует `make` для упрощения управления различными сервисами. Ниже приведены команды для запуска и управления различными компонентами приложения.

### Доступные команды

| Команда           | Описание                                                                  |
| ----------------- | ------------------------------------------------------------------------- |
| `make all`        | Запускает все сервисы, необходимые для работы приложения.                  |
| `make psql`       | Запускает базу данных PostgreSQL.                                           |
| `make redis`      | Запускает хранилище данных Redis.                                          |
| `make both`       | Запускает все сервисы Next.js (production build и локальный сервер).        |
| `make websocket` | Запускает WebSocket сервер, обеспечивающий взаимодействие в реальном времени. |

### Подробное описание команд

*   **`make all`**: Эта команда является основной для запуска всего приложения. Она оркестрирует запуск всех необходимых сервисов, таких как PostgreSQL, Redis, Next.js (включая сборку для production и запуск сервера), и WebSocket сервер.  Используйте эту команду для быстрого старта всего проекта.

*   **`make psql`**:  Эта команда запускает базу данных PostgreSQL. Убедитесь, что PostgreSQL установлен и настроен на вашей системе перед использованием этой команды.

*   **`make redis`**: Запускает сервер Redis. Redis используется для [опишите для чего используется Redis, например: кэширования данных, управления сессиями, обмена сообщениями и т.д.]. Перед запуском убедитесь, что Redis установлен и настроен.

*   **`make both`**: Эта команда запускает два процесса Next.js:
    1.  Сначала она выполняет сборку приложения Next.js для production (`next build`).
    2.  Затем запускает сервер Next.js (`next start`), который обслуживает production сборку.
        Используйте эту команду для запуска Next.js приложения в режиме, готовом к развертыванию.

*   **`make websocket`**: Запускает WebSocket сервер. Этот сервер [опишите назначение WebSocket сервера, например:  обеспечивает двустороннюю связь между клиентом и сервером для [функциональность, использующая websockets, например: чата, уведомлений в реальном времени, онлайн игр]].

### Примечания

*   Перед выполнением этих команд убедитесь, что у вас установлены все необходимые зависимости (PostgreSQL, Redis, Node.js, npm/yarn).
*   Проверьте конфигурационные файлы (если таковые имеются) для настройки портов и других параметров.
*   Если вы вносите изменения в код, возможно, потребуется перезапустить соответствующие сервисы.
